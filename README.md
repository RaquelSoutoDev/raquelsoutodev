## 👋 About Me
 
Hi, I'm Raquel! Software Developer at **LICO Cosmetics**, where I build what keeps an e-commerce running behind the scenes: a custom Shopify app, integrations, automations and internal tools.
 
Self-taught at heart, Computer Engineering student by discipline. Lately I've been following my curiosity beyond the web, towards Python, systems, data and cloud.
 
And yes, I've also built video games just for the fun of it 🎮
 
```
Web / E-commerce → Software Engineering → Python → Systems / Data → Cloud / DevOps
```
 
---
 
## 💼 Experience
 
### 🧴 Software Developer · LICO Cosmetics
 
My work goes a bit beyond "doing Shopify". Day to day, I'm involved in:
 
- 🧩 **Custom Shopify app**: an embedded app built with Remix, Node.js, Prisma and PostgreSQL
- 🎁 **Commerce logic**: bundles, loyalty program and tiered discounts
- 🚚 **Logistics integrations**: carrier tracking, order flows and cash-on-delivery processes
- 🔌 **APIs & automation**: connecting external services and automating repetitive processes
- 🛠️ **Internal tools** for the team
- 🎨 **Shopify themes** developed and customized with Liquid
- 🧯 **Troubleshooting** across the platforms the company runs on, like Shopify and Gorgias
- 🧭 Taking part in the **technical direction** of our projects
